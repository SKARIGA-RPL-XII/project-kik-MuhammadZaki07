# Release Notes - Gagal Lapar

## Version 1.0.0-beta (Current)
Penyelesaian fungsionalitas inti untuk kebutuhan penilaian Tugas Akhir.

### Logika & Fitur Selesai:
* Autentikasi Multi-role (Admin, Kasir, Karyawan, Pelanggan).
* Manajemen Menu dan Kategori.
* Sistem Kasir/POS (Point of Sales).
* Integrasi Gateway Pembayaran (Simulasi).

### Fitur dalam Pengembangan (Prioritas):
* Laporan Penjualan (Export PDF/Excel).
* Manajemen Stok otomatis (Inventory Tracking).
* Dashboard Analytics Pendapatan.

### Perbaikan Sistem:
* Optimasi query database untuk loading menu yang lebih cepat.
* Pembersihan kode (Code Cleaning) pada bagian integrasi library JavaScript.
